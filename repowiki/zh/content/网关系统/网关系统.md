## 简介
本文件面向 OpenClaw 网关系统，聚焦于 WebSocket 控制平面的实现原理、协议规范与通信机制，系统性阐述网关的配置选项、认证流程、心跳监控与发现机制，并覆盖生命周期管理、状态同步与错误处理策略。同时提供 API 接口规范、消息格式定义与客户端集成指南，以及监控指标、性能调优与故障排除方法。

## 项目结构
网关系统由多个子模块协同工作：认证与网络解析（auth、net）、WebSocket 工具（infra/ws）、启动引导（boot）、心跳与自动回复（auto-reply/heartbeat）、插件发现（plugins/discovery）。这些模块共同构成控制平面的基础设施与运行时能力。

## 详细组件分析

### 认证与授权（WebSocket 控制平面）
- 模式解析与优先级：支持“无”、“令牌”、“密码”、“受信任代理”，默认令牌模式；可被显式覆盖。
- 凭据来源：配置项与环境变量，支持密钥引用解析；密码模式在启动前需要明文或环境变量。
- 速率限制：对失败尝试按客户端 IP 进行限流，支持重试等待时间返回。
- Tailscale 集成：在非本地直连且允许时，通过反向查询验证用户身份与来源。
- 受信任代理：要求指定用户头与可选白名单，严格校验代理链与必需头。
- 授权入口：HTTP 与 WS 控制 UI 两种表面，后者允许基于 Tailscale 头部免令牌登录。

### 网络与地址解析（绑定与安全）
- 绑定主机策略：支持 loopback、lan、tailnet、auto、custom，具备回退与可绑定测试。
- 客户端 IP 解析：从 socket 远端地址、X-Forwarded-For、X-Real-IP 解析，尊重可信代理链。
- 地址判定：回环、私网/环回、本地主机（含 .ts.net）等。
- 安全 WebSocket URL：默认仅允许 wss，ws 仅限回环；可选允许私有网络覆盖。

## 性能考量
- 插件发现缓存：默认短缓存窗口减少重复扫描开销，可通过环境变量禁用或调整。

## 故障排除指南
- 认证失败
  - 检查令牌/密码是否正确配置，确认启动前密码必须为明文或环境变量。
  - 若启用受信任代理，确认代理链与必需头存在且用户在白名单中。
  - 若被限流，等待重试间隔后重试。
- WebSocket 不安全
  - 默认仅允许 wss；ws 仅限回环。若需在私网使用 ws，请评估安全策略。
- 绑定失败
  - 切换绑定模式（如从 tailnet 回退到 lan 或 auto），或更换自定义地址。
- 引导失败
  - 查看引导执行与会话映射恢复的错误信息，定位具体环节。
- 心跳无效
  - 确认心跳内容非空且包含有效任务；确认未被剥离为跳过状态。
